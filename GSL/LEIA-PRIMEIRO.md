# GSL 4.3 (entrega de 26/11)

- `GSL-4.3-26-11.zip` — o projeto inteiro: o código do Apps Script, a pasta GSL-Local já montada, as ferramentas e os testes.
- `codigo/` — os arquivos para colar no Apps Script (cada `.gs` como Script e cada `.html` como HTML, com o nome sem a extensão). Depois: Implantar › Gerenciar implantações › Nova versão.
- `GSL-Local/` — a versão da pasta compartilhada. Copie a pasta para o servidor de arquivos e edite o `gsl-config.js` com o endereço `/exec` da implantação (que precisa estar com "Quem pode acessar: Qualquer pessoa").
- `LEIA-ME.md` — o que mudou em cada entrega e como publicar (comece pela seção "Entrega de 26/11").
